Build your own link page for free —
no Linktree needed.

Linktree charges you monthly for something you can own forever. Here's how to build your own branded link page with nothing but a text editor and a free GitHub account.

MCKNZ March 2026 · 6 min read

If you've ever paid for Linktree, Later, or any other "link in bio" tool — I have good news. You've been paying for something you can build yourself in about an hour, host for free, and own completely. No monthly fees. No platform lock-in. Your own domain.

This is exactly what I built for The Pink Pooch — a local pet grooming business that needed a clean, branded page to replace their Linktree. The result looks way better, loads faster, and costs nothing per month.

What you'll need: A free GitHub account, a text editor (even Notepad works), and optionally a custom domain (~$15/year from Namecheap or Cloudflare). That's it.

What you're building

A single HTML file that lives on GitHub Pages — GitHub's free static hosting. It'll have your photo or logo, your name/brand, and a list of links that visitors can tap. It's mobile-first by design because that's where 95% of "link in bio" traffic comes from.

Step by step

01

Create a GitHub repository

Sign into GitHub and create a new repository. Name it exactly yourusername.github.io — this gives you a free URL at that same address automatically. Make sure it's set to Public.

02

Create your index.html file

In your new repo, click Add file → Create new file. Name it index.html. Paste in the template below and customize it with your details.

index.html — starter template 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8"/>
  <meta name="viewport" content="width=device-width, initial-scale=1.0"/>
  <title>Your Name — Links</title>
  <style>
    * { box-sizing: border-box; margin: 0; padding: 0; }
    body {
      font-family: sans-serif;
      background: #fafafa;
      min-height: 100vh;
      display: flex;
      justify-content: center;
      padding: 3rem 1.5rem;
    }
    .card {
      max-width: 420px;
      width: 100%;
      text-align: center;
    }
    img {
      width: 90px; height: 90px;
      border-radius: 50%;
      object-fit: cover;
      margin-bottom: 1rem;
    }
    h1 { font-size: 1.2rem; margin-bottom: .25rem; }
    .bio { font-size: .85rem; color: #888; margin-bottom: 2rem; }
    a.link-btn {
      display: block;
      background: #fff;
      border: 1px solid #e5e5e5;
      border-radius: 8px;
      padding: .9rem 1rem;
      margin-bottom: .75rem;
      font-size: .9rem;
      color: #111;
      text-decoration: none;
      transition: background .15s;
    }
    a.link-btn:hover { background: #f0f0f0; }
  </style>
</head>
<body>
  <div class="card">
    <img src="photo.jpg" alt="Your Name"/>
    <h1>Your Name</h1>
    <p class="bio">Short tagline or description</p>

    <a href="https://instagram.com/yourhandle" class="link-btn">
      Instagram
    </a>
    <a href="https://yourwebsite.com" class="link-btn">
      Website
    </a>
    <a href="mailto:you@email.com" class="link-btn">
      Email me
    </a>
  </div>
</body>
</html>
03

Enable GitHub Pages

Go to your repo's Settings → Pages. Under "Source", select Deploy from a branch, choose main, and hit Save. Within a minute or two, your page will be live at yourusername.github.io.

04

Add a custom domain (optional but worth it)

Buy a domain like links.yourbrand.com for ~$15/year. In your domain registrar's DNS settings, add a CNAME record pointing to yourusername.github.io. Then add that domain in your GitHub Pages settings. GitHub handles the SSL certificate automatically.

Making it look like you

The template above is intentionally bare. The fun part is making it yours. A few easy wins:

  • Change the background color to match your brand
  • Use a Google Font that fits your vibe — just add a <link> tag in the <head>
  • Add icons from a free library like Lucide or just use emoji
  • Upload a square photo and reference it as photo.jpg in the same folder

Updating your links later

Whenever you need to change a link, just edit your index.html file directly on GitHub (click the pencil icon), make your change, and commit. It goes live in about 30 seconds. No login to a third-party app, no subscription required.

It's not as slick as a dashboard, but for most small businesses updating links once a month? It's more than enough. And if you want a proper admin interface so you can edit without touching code at all — that's a service I offer too.

That's it

You now have a free, fully-owned link page on your own domain. No Linktree. No monthly fees. No algorithms deciding if your account gets suspended. Just a file you own, on hosting you control.
